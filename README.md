# Изучение SQL по книге Уолтера Шилдса «SQL: быстрое погружение»

Практика работы с реляционной базой данных музыкального магазина **sTunes** в **Supabase (PostgreSQL)**.

## Структура репозитория
* `00_init_stunes.sql` — создание таблиц базы данных `sTunes` и наполнение данными.
* `ch03_explore.sql` — знакомство с базой данных и первые тестовые запросы (Глава 3).
* `ch04_basic_queries.sql` — выборка (`SELECT`), псевдонимы (`AS`), сортировка (`ORDER BY`) и `LIMIT` (Глава 4).
